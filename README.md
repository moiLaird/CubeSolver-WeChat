# Cube Solver - 微信小程序魔方求解器

基于微信小程序平台的三阶魔方（Rubik's Cube）拍照识别与自动求解应用。
采用 Kociemba 两阶段算法，支持相机扫描识别与手动状态输入两种方式。

## 设计目的

本项目旨在为魔方爱好者提供一个轻量、便捷的手机端求解工具：

- **降低求解门槛**：无需记忆复杂公式，相机一拍即可获取还原步骤。
- **便携与即时**：依托微信小程序，无需安装独立 App，即用即走。
- **学习辅助**：通过分步动画展示还原过程，帮助用户理解每一步操作。

## 实现功能

### 1. 首页（index）
- 展示应用入口与功能导航。
- 支持本地求解器初始化（增量加载移动表与剪枝表，带进度提示）。

### 2. 相机扫描（scan）
- 调用手机摄像头依次拍摄魔方 6 个面。
- **自动色彩分析**：
  - 对每张照片进行 3×3 网格区域采样。
  - 采用 Trimmed-Mean（截尾均值）过滤高光与阴影干扰。
  - 中心块提取参考色，其余块基于 HSV 空间距离分类。
  - 全局约束：每种颜色严格限制为 9 个贴纸，超限自动标为 `?` 供用户修正。
- 支持人工点选修正颜色。
- 一键求解并以 3D 动画展示还原步骤。

### 3. 手动输入（verify）
- 直接输入 54 字符的魔方状态字符串（URFDLB 顺序）。
- 实时校验字符合法性与各颜色数量约束。
- 求解结果即时返回，并附带 3D 动画演示。

### 4. 步骤演示（cube3d 组件）
- 3D 等距投影动态演示还原过程，26 个 cubie 独立渲染。
- 支持播放、暂停、重置控制。
- 基于 Canvas 2D 的手写投影与旋转矩阵，无需外部 3D 库。

## 采用的算法

### 核心求解：Kociemba 两阶段算法

项目底层使用开源库 [`cubejs`](https://github.com/ldez/cubejs)，实现了 Herbert Kociemba 经典的两阶段搜索算法：

| 阶段 | 目标 | 核心数据结构 |
|------|------|-------------|
| **Phase 1** | 将任意魔方状态转化为 **G1 子群**（仅保留 <U, D, R2, L2, F2, B2> 操作） | 扭转（twist）、翻转（flip）、角块/边块排列的坐标编码与移动表 |
| **Phase 2** | 在 G1 子群中搜索完全还原状态 | 剪枝表（Pruning Tables）进行深度优先 IDA* 搜索 |

#### 预计算表（客户端增量初始化）

由于移动表与剪枝表体积较大，客户端采用 **分步增量加载**，共 12 个阶段：

1. `twist` / `flip` / `FRtoBR` / `URFtoDLF` / `URtoDF` / `URtoUL` / `UBtoDF` / `mergeURtoDF` — 移动表（Move Tables）
2. `sliceTwist` / `sliceFlip` / `sliceURFtoDLFParity` / `sliceURtoDFParity` — 剪枝表（Pruning Tables）

初始化时通过 `setTimeout` 分片执行，避免阻塞小程序主线程，并实时反馈进度到 UI。

### 色彩识别算法

| 步骤 | 技术细节 |
|------|---------|
| 颜色空间转换 | RGB → HSV，分离色相（Hue）、饱和度（Saturation）、明度（Value） |
| 区域采样 | 对每个 3×3 单元格取方形区域像素，按亮度排序后截去上下 10% 极值，取中间均值 |
| 动态参考 | 以每个面的中心块作为该面参考色，自适应实际光照条件 |
| 连续权重分类 | 白色检测使用"白度似然度"连续加权，避免硬阈值导致的误判 |
| 全局约束 | 遍历 6 个面，若某颜色超过 9 个，按与参考色距离从远到近标记为 `?` |

## 技术栈

- **前端框架**：微信小程序原生框架（WXML + WXSS + JS）
- **组件化**：自定义 `cube3d` 组件（3D 等距投影，Canvas 2D 渲染）
- **云服务**：微信云开发（云函数 `wx-server-sdk`）
- **求解引擎**：`cubejs`（Kociemba 两阶段算法，JavaScript 实现）

## 项目结构

```
cube_solver/

│   ├── scan/                       # 扫描页：拍照、色彩分析、求解
│   └── verify/                     # 验证页：手动输入 54 字符状态串
├── components/
│   ├── cube3d/                     # 3D 等距立方体动画播放器
│   └── cubePlayer/                 # （历史组件，代码保留备用）
├── utils/
│   ├── solver.js                   # cubejs 封装：增量初始化 + 求解接口
│   └── colorClassifier.js          # 色彩分类：RGB→HSV、采样、全局约束
├── cloudfunctions/
│   └── solve/                      # 云函数：服务端求解备选
└── package.json                    # 依赖声明（cubejs）
```
